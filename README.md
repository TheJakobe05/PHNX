## Features

- **Syntax highlighting** powered by RSyntaxTextArea [by bobbylight](https://github.com/bobbylight/RSyntaxTextArea)
- **File tree sidebar** with drag-and-drop, rename, delete, and new file/folder
- **Multiple themes**
  - Alabaster
  - Cinder & Ash
  - Vaporwave 77
  - Matcha Latte
  - Crème Brûlée
- **Hidden themes** (Fallout, DOOM)
- **Minimap**, line numbers, and status bar
- **Font controls** (including JetBrains Mono detection)
- **Drag & drop** files and folders
- **Image viewer** (opens images in their own window)
- **Ctrl + Scroll** to change font size
- Tons of **Easter eggs**

## Easter Eggs

| Trigger              | Effect                          |
|----------------------|---------------------------------|
| Konami code          | Matrix rain                     |
| Double-click version | Snake game                      |
| Type `disco`         | Theme party mode                |
| Type `gravity`       | Text falls downward             |
| Idle 5 minutes       | DVD logo bounce                 |
| Type `fallout`       | Pip-Boy terminal theme          |
| Type `iddqd`          | DOOM theme                     |
| …and more            | Sound effects, etc.             |
