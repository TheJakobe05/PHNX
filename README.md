## Features

- **Syntax highlighting** powered by RSyntaxTextArea [by bobbylight](https://github.com/bobbylight/RSyntaxTextArea)
- **Advanced Custom Theming (CT)**
  - Dynamic **Installable Themes** support
  - Custom UI color schemes and editor palettes
  - **Custom Emblem & Wallpaper** options for personalized workspace visuals
- **Configuration File Loading** to save and load user preferences automatically
- **File tree sidebar** with drag-and-drop, rename, delete, and new file/folder creation
- **Built-in themes**
  - Alabaster
  - Cinder & Ash
  - Vaporwave 77
  - Matcha Latte
  - Crème Brûlée
- **Hidden themes** (Fallout, DOOM)
- **Minimap**, line numbers, and status bar
- **Font controls** (including JetBrains Mono detection)
- **Drag & drop** files and folders
- **Image viewer** (opens images in their own window)
- **Ctrl + Scroll** to change font size
- Tons of **Easter eggs**

---

## Customization & Config

PHNX supports user configuration files and custom theme installation to tailor your editing experience.

### User Preferences Config
PHNX automatically reads your settings (fonts, active themes, UI options) from a local configuration file on launch.

### Custom Themes & Wallpapers
- **Installable Themes**: Load external theme files directly into PHNX.
- **Custom Emblem & Wallpaper (CT)**: Personalize the workspace background by setting custom emblems or wallpapers directly through the Custom Theming options.

## Getting Started

### Requirements
- Java 17 or higher

### Run
```bash
git clone https://github.com/TheJakobe05/PHNX.git
cd phnx
java -jar PHNX.jar
```
